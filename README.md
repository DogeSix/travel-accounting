## 核心特色總覽（外簡內強）

### 1. 簡單記帳基因：零學習成本九宮格極速輸入
- **九宮格 `3×3` ⇄ 超大按鈕 `2×2` 一鍵切換**：大圓章幾何圖示＋立體機械按鍵下壓回饋與音效。
- **免打字智慧子標籤**：點進分類自動浮現常用詞（早餐、手搖飲、捷運、藥妝店、伴手禮...），不開手機鍵盤 2 秒完成記帳，亦可隨時新增專屬常用詞。
- **內建硬體四則運算算盤**：支援 `1280 + 550 × 2` 連續加減乘除即時試算。
- **頂部「常用秒記・每月固定帳」快捷鍵**：一鍵秒記拿鐵/早餐，並支援房租、電信費、Netflix 每月固定帳單一鍵入帳。

### 2. MOZE 4.0 基因：出國旅遊獨立帳本 × 10 國匯率自動折算
- **台灣日常 ⇄ 出國旅遊多帳本切換**：內建「🇹🇼 台灣日常」、「🇯🇵 日本東京旅帳」、「🇰🇷 韓國首爾旅帳」，並可無限新增各國旅遊專帳（自動綁定當地預設外幣與旅遊總預算）。
- **10 國常用貨幣＋海外刷卡 `+1.5%` 手續費＋免稅 `-10%` 試算器**：支援 `TWD / JPY / KRW / THB / USD / EUR / HKD / CNY / SGD / VND`，連網時自動更新即時匯率，飛機上沒網路自動使用離線快取匯率，也可手動鎖定換匯匯率。
- **月預算水位條 ＆ 今日安全可花額度 (Safe-to-Spend)**：一眼掌握預算剩餘比例與每日可花上限。

### 3. CWMoney 基因：多帳戶連動 × 收支月曆 × 發票對獎 × LINE 分帳
- **支出／收入／轉帳換匯 三模式完整連動**：支援錢包現金、銀行存款、信用卡（含**一鍵繳清卡費**）、LINE Pay、悠遊卡/Suica、外幣現金袋，自動計算總淨資產。
- **感熱紙收支明細 ＆ 互動收支月曆**：清單搜尋篩選、月曆逐日檢視與補記、收據拍照自動壓縮保存、點擊任一筆隨時修改或刪除復原。
- **台灣統一發票極速對獎**：記帳可順手記末 3 碼自動比對，亦提供紙本發票連敲 3 碼秒速對獎器。
- **旅伴 AA 分帳／幫人代買結算單**：支援 `AA平分 (÷2/÷3/÷4)` 與 `幫人代買100%`，自動統計每位旅伴欠款，支援 **「一鍵複製超整齊 LINE 分帳結算單」**！

## 3 分鐘上傳 GitHub 並用手機出國連線使用

本專案採 **零編譯純靜態離線 PWA 架構**，無須設定複雜伺服器或 Node 打包，上傳即用：

1. 登入 GitHub 建立一個新的公開儲存庫（Repository，例如命名為 `haoji-money`）。
2. 點擊 **uploading an existing file**，將本資料夾內的所有檔案（`index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.json`、`.nojekyll`、`icons` 資料夾）直接拖曳上傳並按下 **Commit changes**。
3. 進入該儲存庫的 **Settings → Pages**，在 **Build and deployment → Branch** 選擇 `main`（資料夾 `/root`）並按 **Save**。
4. 等待約 30～60 秒，即可獲得專屬手機網址 `https://<你的帳號>.github.io/haoji-money/`！

### 手機變身全螢幕離線 App（出國沒訊號也能記）
- **iPhone (Safari)**：開啟網址 → 點擊底部中間「分享」圖示 → 選擇 **「加入主畫面」**。
- **Android (Chrome)**：開啟網址 → 點擊右上角「⋮」選單 → 選擇 **「安裝應用程式 / 加到主畫面」**。
